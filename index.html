Motion guidance

One shared scale for micro-interactions on iOS and Android. Only page navigation and sheets fork per platform, because that is where iOS and Android users have learned different spatial models. Bounce is used only for confirmed success.

Duration

A 100 ms grid. The size of the change picks the step, not the component type. Every step is also a Material 3 token, so Android engineers can cross-check. Exits take the next shorter step.

Easing

What arrives slows down, what leaves speeds up, what moves on screen uses standard. The iOS curve is only reached through the navigation and sheet tokens.

Springs

Defined the way SwiftUI does it: a duration and a bounce. In CSS they are pre-sampled into linear(); the CSS duration is the time until the spring visually settles.

Platform-forked tokens

The only tokens that resolve differently per platform. Android is the default; data-platform="ios" on the root element switches to the iOS values. Switch platforms inside the phone to compare.

  • --motion-nav-enter
    iOS: xl + ease-ios · Android: lg + ease-standard. New page covers the old one on iOS; both pages shift 30 px and cross-fade on Android.
  • --motion-nav-exit
    iOS: lg + ease-ios · Android: md + ease-standard. Reverse of enter, driven by the back gesture.
  • --motion-sheet-enter
    iOS: xl + ease-ios, page behind scales to 0.93 · Android: lg + ease-enter over a 32% scrim.
  • --motion-sheet-exit
    iOS: lg + ease-ios · Android: md + ease-exit. Drag-to-dismiss follows the finger, then finishes with spring-smooth.

Supporting tokens

Distances and delays that go with the durations and curves.

Delight

Delight goes to moments that carry emotion: money arriving, something finally ready. Each of those keeps one bouncy element and plays it only after the outcome is confirmed. Activity, card lock and wrong PIN show where motion stays quiet or calm.

Rules

Nine rules for picking the right token. When two rules seem to conflict, the one closer to the top wins.

Edge cases

Situations where following the token tables literally gives the wrong result. Several come from running inside the native app's webview.

Reduce Motion

Swap, don't delete. iOS itself replaces slides with cross-fades when Reduce Motion is on, and we do the same. Turn on the preview at the top of the page to see every example in this mode.

Code

Drop the CSS into the global stylesheet and the TypeScript next to your Motion components. Call applyPlatformAttribute() once at boot so the forked tokens resolve.

motion-tokens.css
/* Motion tokens v1 — mobile-first React (web).
   Durations on a 100 ms grid (subset of Material 3 short2…long2).
   Springs use Apple's duration + bounce model (WWDC23 "Animate with springs"),
   pre-sampled to CSS linear(); the CSS duration is the visual settle time. */

:root {
  /* Duration — size sets the step, exits take the next shorter step */
  --motion-duration-xs: 100ms; /* press feedback, colour/opacity state */
  --motion-duration-sm: 200ms; /* toggle, checkbox, icon swap, tooltip */
  --motion-duration-md: 300ms; /* expand/collapse, menu, toast, tab indicator */
  --motion-duration-lg: 400ms; /* dialog; Android page + sheet */
  --motion-duration-xl: 500ms; /* iOS page push + sheet, full-screen modal */

  /* Easing */
  --motion-ease-standard: cubic-bezier(0.2, 0, 0, 1);      /* moves on screen */
  --motion-ease-enter:    cubic-bezier(0.05, 0.7, 0.1, 1); /* arrives */
  --motion-ease-exit:     cubic-bezier(0.3, 0, 0.8, 0.15); /* leaves */
  --motion-ease-ios:      cubic-bezier(0.32, 0.72, 0, 1);  /* iOS nav + sheets */

  /* Springs (duration, bounce) → linear() */
  --motion-spring-smooth: linear(0, 0.028, 0.094, 0.18, 0.273, 0.366, 0.454, 0.535, 0.607, 0.67, 0.725, 0.772, 0.811, 0.845, 0.873, 0.896, 0.915, 0.931, 0.944, 0.955, 0.963, 0.971, 0.976, 0.981, 0.985, 0.988, 0.99, 0.992, 0.994, 0.995, 1);
  --motion-spring-smooth-duration: 490ms; /* 0.4 s, bounce 0 */
  --motion-spring-snappy: linear(0, 0.025, 0.087, 0.17, 0.265, 0.362, 0.457, 0.545, 0.625, 0.696, 0.757, 0.809, 0.853, 0.889, 0.918, 0.941, 0.96, 0.974, 0.984, 0.992, 0.998, 1.001, 1.004, 1.005, 1.006, 1.006, 1.006, 1.006, 1.005, 1.005, 1);
  --motion-spring-snappy-duration: 340ms; /* 0.3 s, bounce 0.15 */
  --motion-spring-bouncy: linear(0, 0.025, 0.089, 0.178, 0.281, 0.389, 0.496, 0.596, 0.687, 0.768, 0.836, 0.893, 0.939, 0.975, 1.002, 1.022, 1.034, 1.042, 1.045, 1.046, 1.044, 1.04, 1.036, 1.031, 1.026, 1.021, 1.017, 1.013, 1.009, 1.006, 1);
  --motion-spring-bouncy-duration: 450ms; /* 0.4 s, bounce 0.3 — success moments only */

  /* Distances */
  --motion-press-scale: 0.97;
  --motion-offset-xs: 4px;   /* text swap */
  --motion-blur-xs: 2px;     /* text swap */
  --motion-text-swap-duration: 150ms; /* per phase: exit, then enter */
  --motion-offset-sm: 8px;   /* toast / tooltip rise */
  --motion-offset-md: 30px;  /* Android shared-axis slide */
  --motion-stagger: 40ms;    /* max 5 items */

  /* Platform-forked semantic tokens — Android/Material is the default */
  --motion-nav-enter-duration: var(--motion-duration-lg);
  --motion-nav-enter-ease:     var(--motion-ease-standard);
  --motion-nav-exit-duration:  var(--motion-duration-md);
  --motion-nav-exit-ease:      var(--motion-ease-standard);
  --motion-sheet-enter-duration: var(--motion-duration-lg);
  --motion-sheet-enter-ease:     var(--motion-ease-enter);
  --motion-sheet-exit-duration:  var(--motion-duration-md);
  --motion-sheet-exit-ease:      var(--motion-ease-exit);
}

/* Text swap (pattern from Transitions.dev). Driven by JS in three phases:
   1. add .is-exit  → old text lifts, blurs and fades
   2. after --motion-text-swap-duration: change textContent, add .is-enter-start
   3. force reflow, remove .is-enter-start → new text animates back to rest */
.motion-text-swap {
  display: inline-block;
  transform: translateY(0);
  filter: blur(0);
  opacity: 1;
  transition:
    transform var(--motion-text-swap-duration) ease-in-out,
    filter    var(--motion-text-swap-duration) ease-in-out,
    opacity   var(--motion-text-swap-duration) ease-in-out;
}
.motion-text-swap.is-exit {
  transform: translateY(calc(var(--motion-offset-xs) * -1));
  filter: blur(var(--motion-blur-xs));
  opacity: 0;
}
.motion-text-swap.is-enter-start {
  transform: translateY(var(--motion-offset-xs));
  filter: blur(var(--motion-blur-xs));
  opacity: 0;
  transition: none;
}
motion.ts
// Motion tokens v1 for Motion (motion.dev / framer-motion). Motion uses seconds.
// Wrap the app in <MotionConfig reducedMotion="user"> so transform/layout animations
// stop for Reduce Motion users while opacity and colour still animate.

export type Platform = "ios" | "android";

export const duration = { xs: 0.1, sm: 0.2, md: 0.3, lg: 0.4, xl: 0.5 } as const;

export const ease = {
  standard: [0.2, 0, 0, 1],
  enter: [0.05, 0.7, 0.1, 1],
  exit: [0.3, 0, 0.8, 0.15],
  ios: [0.32, 0.72, 0, 1],
} as const;

// Apple-style springs: visualDuration + bounce (same model as SwiftUI).
export const spring = {
  smooth: { type: "spring", visualDuration: 0.4, bounce: 0 },
  snappy: { type: "spring", visualDuration: 0.3, bounce: 0.15 },
  bouncy: { type: "spring", visualDuration: 0.4, bounce: 0.3 }, // success moments only
} as const;

export const press = { scale: 0.97, transition: { duration: duration.xs, ease: ease.standard } } as const;

// Text swap for labels that change in place: exit up + blur, then enter from below.
export const textSwap = {
  exit: { y: -4, filter: "blur(2px)", opacity: 0 },
  enterFrom: { y: 4, filter: "blur(2px)", opacity: 0 },
  rest: { y: 0, filter: "blur(0px)", opacity: 1 },
  transition: { duration: 0.15, ease: "easeInOut" }, // per phase
} as const;

const forks = {
  ios: {
    navEnter: { duration: duration.xl, ease: ease.ios },
    navExit: { duration: duration.lg, ease: ease.ios },
    sheetEnter: { duration: duration.xl, ease: ease.ios },
    sheetExit: { duration: duration.lg, ease: ease.ios },
  },
  android: {
    navEnter: { duration: duration.lg, ease: ease.standard },
    navExit: { duration: duration.md, ease: ease.standard },
    sheetEnter: { duration: duration.lg, ease: ease.enter },
    sheetExit: { duration: duration.md, ease: ease.exit },
  },
} as const;

export function detectPlatform(): Platform {
  if (typeof navigator === "undefined") return "android";
  const ua = navigator.userAgent;
  const isIOS = /iPhone|iPad|iPod/.test(ua) || (/Macintosh/.test(ua) && navigator.maxTouchPoints > 1);
  return isIOS ? "ios" : "android";
}

export const platform = detectPlatform();
export const nav = forks[platform];

// Call once at boot so the CSS tokens resolve per platform too.
export function applyPlatformAttribute() {
  document.documentElement.dataset.platform = platform;
}
